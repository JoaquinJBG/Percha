# Percha

App web instalable (PWA) para tener tu armario en el móvil y que una IA te proponga outfits.

1. Haces una o dos fotos de cada prenda o zapato.
2. Percha recorta el fondo y la IA la etiqueta (tipo, colores, estilo, abrigo, formalidad).
3. Eliges estilo y ocasión; Percha mira el tiempo que hace y te propone **4 outfits** en un collage 2×2.
4. Si quieres verte con ellos, el botón **«Pruébatelo en Gemini»** manda tus fotos y las prendas a tu app de Gemini.

**Coste cero:** no hay servidor. La app se aloja gratis, los datos se guardan en tu móvil y la IA usa la
clave gratuita de Gemini de cada usuario.
